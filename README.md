# Resona — מנתח חלל ומערכת הגברה

אפליקציית ווב למדידת סאונד וכיוון מאסטר של מערכת הגברה לפי היענות החלל. רצה בדפדפן בטלפון, בטאבלט ובמחשב, ואפשר להתקין אותה כאפליקציה על מסך הבית.

## מה יש בפנים

- **מד SPL** עם שקלולים A / C / Z, תגובות Fast / Slow / Leq, Max ו־Peak, והיסטוריית רמה של 60 שניות.
- **עוצמת יעד**: בוחרים עוצמה, והאפליקציה מראה בכמה dB להזיז את המאסטר.
- **מנתח RTA בסגנון Pro‑Q**: החלקה מ־1/48 עד 1/1 אוקטבה, מיצוע מהיר / איטי / מצטבר, FFT בגדלים 8k / 16k / 32k, שיא, עקומת יעד וקו "צפוי אחרי EQ".
- **EQ אינטראקטיבי**: עד 8 פסים (Bell, Shelf, Cut, Notch). גוררים נקודה, ומשנים Q בגלגלת או בצביטה עם שתי אצבעות.
- **הצעת EQ אוטומטית** לפי עקומת יעד (House, הופעה, מועדון, דיבור) והטיה. חיתוכים קודמים להגברות, ושקעים צרים מסומנים כביטולי חדר.
- **עומסים לפי תחום**: בסיסי (6 תחומים) או מפורט (11 תחומים, 20 Hz עד 20 kHz).
- **זיהוי הצטברויות ותהודות** עם שם התו, וכפתור חיתוך מהיר.
- **ממוצע מרחבי** מכמה מיקומי מדידה בקהל, ותמונות להשוואת לפני ואחרי.
- **תצוגות**: ספקטרום, פסי 1/3 אוקטבה, ספקטרוגרמה וצורת גל עם Crest ו־Headroom.
- **מסך מלא**: תצוגה לרוחב בצבעים לפי תדר, משוקללת לפי רגישות האוזן.
- **מחולל רעש**: ורוד, לבן וחום.
- **פרופילי מיקרופון**: אייפון, אייפד, אנדרואיד, מיקרופון USB לטלפון, UMIK / iMM‑6C, וכרטיס קול עם מיקרופון מדידה. אפשר לטעון קובץ כיול אישי ולכייל רמה מול קלברטור או מד ייחוס.
- **ציון אמינות** שבודק עיבוד אות, פרופיל, כיול, רמת אות וטווח תדרים.

## העלאה ל־GitHub Pages

1. צור ריפו חדש ב־GitHub, למשל `resona`.
2. העלה את כל הקבצים מהתיקייה הזו לשורש הריפו: Add file ← Upload files ← גרור הכל ← Commit.
3. היכנס ל־Settings ← Pages. תחת Source בחר Deploy from a branch, ענף `main`, תיקייה `/ (root)`, ושמור.
4. אחרי דקה־שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/resona/`.

המיקרופון עובד רק בכתובת HTTPS, וזה מה ש־GitHub Pages נותן אוטומטית.

## התקנה כאפליקציה

- **אייפון / אייפד:** פתח את הכתובת ב־Safari, לחץ על "שיתוף" ואז "הוסף למסך הבית".
- **אנדרואיד:** פתח ב־Chrome, ובתפריט ⋮ בחר "התקן אפליקציה".

אחרי ביקור אחד עם אינטרנט, האפליקציה עובדת גם בלי חיבור. זה שימושי באולמות בלי קליטה.

## טיפים למדידה אמינה

- **אשר גישה למיקרופון.** האפליקציה מבקשת אות גולמי, בלי AGC, בלי הפחתת רעש ובלי ביטול הד. אם הדפדפן משאיר עיבוד פעיל, ציון האמינות יראה את זה.
- **בחר פרופיל.** בחר את הפרופיל המתאים למיקרופון, ואם יש לך מיקרופון מדידה, טען את קובץ הכיול האישי שלו.
- **כייל רמה.** כייל מול קלברטור (94 / 114 dB) או מול מד SPL מכויל.
- **מדוד בכמה נקודות.** מדוד 3–6 נקודות בקהל והוסף כל אחת ל"מיקומי מדידה" לפני שמחשבים EQ.
- **השתמש ברעש ורוד.** לכיוון משתמשים ברעש ורוד, בעוצמה שגבוהה ב־10 dB לפחות מרעש הרקע.

> פרופילי מיקרופוני הטלפון המובנים הם הערכה. לדיוק מלא צריך מיקרופון מדידה עם קובץ כיול וכיול רמה.

## מבנה

```
index.html             האפליקציה כולה (HTML + CSS + JS, בלי תלויות)
manifest.webmanifest   הגדרות התקנה כאפליקציה
sw.js                  שמירה לשימוש בלי אינטרנט
icons/                 אייקונים
.nojekyll              מונע עיבוד Jekyll ב־GitHub Pages
```

כשמעדכנים את `index.html`, הגרסה החדשה נטענת אוטומטית בביקור הבא עם אינטרנט. אם משנים קבצים אחרים, העלה את הגרסה ב־`sw.js` (למשל `resona-v2`).
